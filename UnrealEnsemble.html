About this Project

Unreal Ensemble is a collaborative Unreal Engine project with Veldboom Studios and Escher Verse. It blends architectural visualization, interactive environments, and gameplay mechanics. The project emphasizes performance-optimized environments, polished visuals, and functional systems.

Challenges

  • Blending ArchViz and interactive systems
  • Character animation and AI behavior
  • Cross-team collaboration and remote workflow
  • Optimizing performance for large environments

Contributions

  • Environment construction and optimization (Nanite & Lumen)
  • Lighting & material refinement for consistent visuals
  • Component Filter system for in-editor workflow improvements
  • Character motion system (walk, run, jump, crouch, climb, sit, prone)
  • AI system development for dynamic character interaction
  • Animation retargeting for 3D Models
  • Interactive mechanics: doors, furniture, color-changing objects
  • Debugging, QA, and cross-version Unreal maintenance

Intro

Unreal Ensemble combines my work in ArchViz, animation, and gameplay systems. I contributed to both the visual fidelity of environments and the technical backbone of interactive features. The project was my largest Unreal collaboration to date.

Development

Phase 1 – Prototyping (2023)

Initial environment setup, lighting passes, and UI prototyping. Started character motion system supporting walk, run, jump, and crouch. Tested climbing, sitting, and prone interactions.

Phase 2 – Consolidation (2024)

Expanded AI systems for multiple characters, retargeted animations to MetaHumans and Grio characters. Integrated Variant Manager for asset & UI synchronization. Optimized environments for runtime performance while refining lighting and materials.

AI & Animation Setup

Phase 3 – Mechanics & Tools (Late 2024 – 2025)

Built interactive systems (doors, furniture, color-changeable objects), managed Git repository, developed game launcher, and implemented Niagara effects for polish.
